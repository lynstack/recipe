import { styleRecipeSpeedup } from "../../../measurements/native-recipe.ts";

`@lynstack/native-recipe` maps a component's variants to its React Native
styles. It has three functions:

- [`createStyleRecipe`](/recipe/native-recipe/create-style-recipe/) creates
  a recipe for the style of one element.
- [`createSlotStyleRecipe`](/recipe/native-recipe/create-slot-style-recipe/)
  creates a slot recipe for the styles of several elements, such as a
  button's container and label.
- [`createThemedRecipes`](/recipe/native-recipe/create-themed-recipes/)
  returns both, for recipes whose styles are built from the tokens of a
  theme.

```ts
import { createStyleRecipe } from "@lynstack/native-recipe";

const badge = createStyleRecipe({
  base: { alignSelf: "flex-start", borderRadius: 999, paddingHorizontal: 8 },
  variants: {
    tone: {
      neutral: { backgroundColor: "#f3f4f6" },
      danger: { backgroundColor: "#fee2e2" },
    },
    size: { sm: { height: 20 }, md: { height: 24 } },
  },
  defaultVariants: { size: "md" },
});

badge({ tone: "danger" });
// => { alignSelf: "flex-start", borderRadius: 999, paddingHorizontal: 8, backgroundColor: "#fee2e2", height: 24 }

badge({ tone: "danger" }) === badge({ tone: "danger" }); // => true
```

## What it gives you

- **Stable styles.** A recipe builds the style of each selection once and
  returns the same frozen object for it. The `style` prop keeps its
  identity between renders, so React skips comparing it and a memoized
  child skips rendering (see
  [How it works](/recipe/native-recipe/how-it-works/)).
- **Type-safe.** Every style is checked against the styles of React
  Native, as in `StyleSheet.create`, and the result keeps the types of the
  properties the config declares: a text style passed to a `View` is a
  type error. Variant names, options, and slots are inferred from the
  config, and a variant without a default is required.
- **Themes.** Build styles from the tokens of a design system, and switch
  between light and dark, or any theme, without declaring each theme's
  styles in every recipe (see
  [Themes and design tokens](/recipe/native-recipe/themes/)).
- **Fast.** A call with the cache is a lookup, about {styleRecipeSpeedup}
  times as fast as merging the styles again (see
  [Performance](/recipe/native-recipe/performance/)).
- **Small.** ES modules only, with no code from React Native at runtime.
  Its one dependency is [`@lynstack/recipe`](/recipe/recipe/), the engine
  it is built on.

## When to use it

Use it to style React Native components whose styles depend on their
props or state. To style components on the web with class names, use
[`@lynstack/class-recipe`](/recipe/class-recipe/); to map variants to
other values, use [`@lynstack/recipe`](/recipe/recipe/).
