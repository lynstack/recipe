## TypeScript setup

In an Expo app, `tsconfig.json` extends `expo/tsconfig.base`, which works
as it is. A React Native CLI app extends `@react-native/typescript-config`,
which works too.

A tsconfig that you write by hand can report errors inside React Native's
own type declarations. Some, such as `Duplicate identifier 'FormData'`,
come from the DOM types, which declare the same globals as React Native.
Others come from React Native's declarations themselves, which do not
compile without `skipLibCheck`. Set `skipLibCheck`, and leave the DOM out
of `lib`:

```jsonc title="tsconfig.json"
{
  "compilerOptions": {
    // Next to your other options, such as "jsx" and "module".
    "lib": ["ES2022"],
    "skipLibCheck": true,
    "strict": true,
  },
}
```
