class-recipe solves the same problem as
[class-variance-authority](https://cva.style) and
[tailwind-variants](https://www.tailwind-variants.org): turning component
props into class names. It differs from them in these ways:

|                           | class-recipe <code>{measurements.versions["class-recipe"]}</code> | class-variance-authority <code>{measurements.versions["class-variance-authority"]}</code> | tailwind-variants <code>{measurements.versions["tailwind-variants"]}</code>, lite |
| ------------------------- | ----------------------------------------------------------------- | ----------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Slots                     | Yes                                                               | No                                                                                        | Yes                                                                               |
| Variant without a default | Required by its type                                              | Optional                                                                                  | Optional                                                                          |
| Conflict resolution       | Any join function, cached                                         | Call `twMerge` on the result                                                              | `tailwind-merge`, built in                                                        |
| Extending a recipe        | `composes`                                                        | No                                                                                        | `extend`                                                                          |
| Recipe calls per second   | {formatRoughHz(recipeSpeedOf("class-recipe"))}                    | {formatRoughHz(recipeSpeedOf("class-variance-authority"))}                                | {formatRoughHz(recipeSpeedOf("tailwind-variants"))}                               |

The calls per second come from the
[benchmarks](/recipe/class-recipe/performance/#recipes).

To move recipes over, see
[Migrating from class-variance-authority](/recipe/class-recipe/migrating-from-cva/)
and
[Migrating from tailwind-variants](/recipe/class-recipe/migrating-from-tailwind-variants/).
