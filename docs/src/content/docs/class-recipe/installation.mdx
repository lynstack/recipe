import { Aside, TabItem, Tabs } from "@astrojs/starlight/components";

<Tabs syncKey="package-manager">
  <TabItem label="npm">

```sh
npm install @lynstack/class-recipe
```

  </TabItem>
  <TabItem label="pnpm">

```sh
pnpm add @lynstack/class-recipe
```

  </TabItem>
  <TabItem label="yarn">

```sh
yarn add @lynstack/class-recipe
```

  </TabItem>
</Tabs>

The package is ESM only and targets ES2022. Its types require TypeScript
5.4 or newer.

<Aside type="tip" title="Using a coding agent?">
  Install the [agent skill](/recipe/class-recipe/agent-skill/) too. It teaches
  Claude Code, Codex, Cursor, and other agents to write recipes whose classes
  never conflict.
</Aside>
