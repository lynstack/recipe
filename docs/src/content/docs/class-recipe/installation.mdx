Its one dependency is [`@lynstack/recipe`](/recipe/recipe/).

The package is an ES module only. Bundlers and frameworks load it as it
is. In a plain Node.js script, use `import`, and either set
`"type": "module"` in your `package.json` or name the file `.mjs` or
`.mts`.

With Tailwind CSS, [set up your editor](/recipe/class-recipe/editor-setup/)
to complete and sort the classes in your recipes.
